## chatty-art
| Term | Alternate term(s) | Alt map | External map | Relation to existing terminology | What it is | What it is not | Source |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Chatty-art | chatty art | ~ | ~ | Local-first media generation app | Offline media generator for images, GIFs, video, and audio with a Rust backend and single-page dashboard surface | Not a cloud service; not tied to one model family only | chatty-art/README.md; chatty-art/USER_MANUAL.md |
| Expressive mode | expressive lane | ~ | ~ | Simple all-in-one generation lane | Generation path that uses the bundled `llama.cpp` runtime plus Chatty-art's local renderer for simpler image/GIF/audio workflows | Not the `stable-diffusion.cpp` realism backend; not the advanced multi-part realism path | chatty-art/README.md |
| Realism mode | realism lane | ~ | ~ | Higher-fidelity backend lane | Local `stable-diffusion.cpp`-based workflow for realism image/video/audio jobs with family-specific helper files and advanced controls | Not a cloud image API; not guaranteed to work with only one GGUF dropped in | chatty-art/README.md |
| Prompt Assist | prompt compiler | ~ | ~ | Local prompt-expansion helper | Optional stage that expands a short user prompt into a richer local handoff before generation | Not the final generator itself; not required for every run | chatty-art/README.md |
| Vision Assist | vision helper, multimodal helper | ~ | ~ | Reference-image interpretation helper | Optional still-image analysis stage that reads a guide or edit reference before Prompt Assist expands the final handoff | Not general internet vision; not active without a still-image reference workflow | chatty-art/README.md |
| Input Tray | tray | ~ | ~ | Asset picker / assignment surface | UI area that exposes files from both `input/` and prior `outputs/` so they can be reused as guide, edit, or voice-reference inputs | Not a permanent asset database; not limited to newly imported files | chatty-art/README.md |
| Guide / Edit Selected | use as guide, edit selected | ~ | ~ | Reference-driven generation controls | Input Tray actions that assign a selected still image either as a guiding reference or as the source image for an edit workflow | Not generic file-open actions; not the same as plain prompt-only generation | chatty-art/README.md |
| Sequential Batch Count | sequential batch | ~ | ~ | Repeat-run control | Setting that reruns the same job one generation at a time with a fresh random seed for each pass | Not one giant simultaneous batch; not fixed-seed replay | chatty-art/README.md |
| Low VRAM Mode | safe VRAM mode | ~ | ~ | Conservative hardware mode | Safer realism launch profile that spills more work to CPU and uses more cautious runtime settings on tighter GPUs | Not a quality boost; not a guarantee that any model will fit | chatty-art/README.md |
| ECG Window | activity graph | ~ | ~ | Honest local activity monitor | Small Windows activity graph shown under the progress area so long local jobs visibly look alive | Not deep telemetry; not a full performance suite | chatty-art/README.md; chatty-art/ecg_window.md |
| Recommended Limits On This Hardware | hardware guidance, recommended limits | ~ | ~ | Hardware-aware UI guidance | Model-aware UI hinting for safer resolution / duration / FPS expectations on the current machine | Not hard enforcement; not a benchmark leaderboard | chatty-art/README.md |
| Realism + Advanced | advanced realism controls | ~ | ~ | Power-user control surface | Expanded control set for realism-capable models including sampler, scheduler, reference strength, flow shift, and family-aware LoRA rows | Not the beginner path; not shown for unsupported families | chatty-art/README.md |
| Manual Focus Cues | focus cues | ~ | ~ | Prompt-handoff steering field | Short manual cue field for emphasizing specific visual priorities when automatic prompt expansion misses them | Not a full prompt replacement; not a separate model | chatty-art/README.md |
| Manual Defaults / Assumptions | defaults, assumptions | ~ | ~ | Prompt-handoff steering field | Manual field for locking in sensible concrete assumptions that the expanded handoff should treat as given | Not metadata storage; not a guarantee the model will obey every assumption | chatty-art/README.md |
| Voice Reference | voice cloning reference | ~ | ~ | Reference-audio assignment | Input Tray assignment that passes a short audio clip to realism speech models like `OuteTTS` as the cloning reference | Not text prompting; not used by non-speech audio lanes | chatty-art/README.md |
| Audio prompt split | Words / Script, Words / Sounds | ~ | ~ | Literal-content lane for audio models | Dedicated field that holds exact spoken words for speech models or literal cue words for soundscape models while the descriptive prompt handles style and intent | Not the same thing as the descriptive prompt; not ignored by realism speech/audio workflows | chatty-art/README.md |
| LoRA (Chatty-art) | local LoRA stack | ~ | ~ | Family-matched adaptation add-on | Small stacked LoRA workflow for realism models where each LoRA is selected from a matching family folder and gets its own strength slider | Not a base model replacement; not cross-family interchangeable by default | chatty-art/README.md |
