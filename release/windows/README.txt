Chatty Art - Windows portable release v0.4.1

Double-click:

  Run Chatty Art.bat

Included binary:

  chatty-art.exe

Writable folders are created beside the launcher on first run.

For voice cloning, Chatty Art normalizes the selected audio reference with
FFmpeg before it is passed to OuteTTS. A short, clear clip (20 seconds or
less) is recommended; WAV, M4A/AAC, and MP3 work when FFmpeg can read them.
